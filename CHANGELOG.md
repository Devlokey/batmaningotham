# Changelog

All notable changes to the `batmaningotham` project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [2.0.0] - 2026-08-09

### Added
- **Fused Engine Architecture:** Integrated **Ponytail Senior-Dev Efficiency** (minimal secure diffs, root-cause enforcement, stdlib reuse) and **Gauntlet Audit Proof Ledger** (zero trust, direct REST/API bypass testing, un-cheatable DoD matrix).
- **13 Core Security Pillars:** Comprehensive coverage of Auth, Multi-Tenancy RLS, API Math, Secrets, Data Privacy, Backups, Rate Limiting, Prompt Injection, AI Tool Isolation, Terms of Service, and IP Licensing.
- **Modular Reference Files:** Created `references/ponytail_pragmatics.md`, `references/gauntlet_audit_ledger.md`, `references/ai_and_llm_security.md`, and `references/web_and_cloud_security.md`.
- **Automated Checkers & Test Suite:** Added static secret scanner (`scripts/check_secrets.py`), SQL tenancy validator (`scripts/audit_tenancy.sql`), and structural tests (`tests/`).
- **Comprehensive Documentation:** Upgraded `README.md` with before/after code examples, empirical benchmarks, and visual flowcharts.
